# F7 — Stripe e assinatura: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** dar chamador real a `Subscription#activate!/#mark_past_due!/#cancel!` via webhook idempotente do Stripe + checkout/portal por escopo (conta direta e agência), com painel no super admin.

**Architecture:** controller de webhook fino (verifica assinatura, garante idempotência via `find_or_create_by!` + `with_lock`) delegando mutação a `StripeBilling::EventHandler`; checkout/portal como services (`StripeBilling::CheckoutSession`/`PortalSession`) chamados por dois controllers finos (um por escopo de dono). Spec: `docs/superpowers/specs/2026-08-06-f7-stripe-design.md`.

**Tech Stack:** Rails, gem `stripe ~> 18.0`, Administrate, RSpec (request specs no CI do espelho).

### Task 3: `StripeBilling::EventHandler`

**Files:**
- Create: `hdevCRM/app/services/stripe_billing/event_handler.rb`
- Test: `hdevCRM/spec/services/stripe_billing/event_handler_spec.rb`

**Interfaces:**
- Consumes: `StripeWebhookEvent` (payload jsonb já gravado), `Subscription#activate!/#mark_past_due!/#cancel!`, `Plan.find_by(stripe_price_id:)`.
- Produces: `StripeBilling::EventHandler.new(event).call` → `nil` (processado) ou `String` (motivo de ignore). NUNCA cria Subscription.

Estrutura (payload é o hash jsonb; `data.object` dentro):

```ruby
class StripeBilling::EventHandler
  def initialize(event) = (@event = event)

  def call
    case @event.event_type
    when 'checkout.session.completed' then handle_checkout_completed
    when 'invoice.paid' then handle_invoice(:paid)
    when 'invoice.payment_failed' then handle_invoice(:failed)
    when 'customer.subscription.updated' then handle_subscription_updated
    when 'customer.subscription.deleted' then handle_subscription_deleted
    end
  end
  # handle_*: localizam a Subscription conforme o spec de design; sem match → devolvem string-motivo.
end
```

- `handle_checkout_completed`: `Subscription.find_by(id: object['client_reference_id'])`; grava `stripe_customer_id: object['customer']` e `activate!(stripe_subscription_id: object['subscription'])`.
- `handle_invoice`: acha por `object.dig('parent','subscription_details','subscription')` → `stripe_subscription_id`; fallback `object['customer']` → `stripe_customer_id`. paid → `activate!(current_period_end: Time.zone.at(max lines period end))` (tolera lines vazio → nil); failed → `mark_past_due!`.
- `handle_subscription_updated`: acha por `object['id']`; sincroniza plano (`items.data[0].price.id` → `Plan.find_by(stripe_price_id:)`; sem plano local → motivo-ignore), status (active/trialing→activate!; past_due/unpaid→mark_past_due!; demais→nada) e `current_period_end` (max de `items.data[].current_period_end`).
- `handle_subscription_deleted`: acha por `object['id']` → `cancel!`.
- [ ] Spec unitária: mapeamento dos 8 status, órfão devolve motivo, price desconhecido devolve motivo, troca de plano grava, lines vazio não explode.
- [ ] Commit.

### Task 4: `Webhooks::StripeController`

**Files:**
- Create: `hdevCRM/app/controllers/webhooks/stripe_controller.rb`
- Test: `hdevCRM/spec/controllers/webhooks/stripe_controller_spec.rb` (request spec)

**Interfaces:** Consumes Task 2 + 3. Segredo: `ENV.fetch('STRIPE_WEBHOOK_SECRET', nil)`.

```ruby
class Webhooks::StripeController < ActionController::API
  HANDLED_EVENTS = %w[checkout.session.completed invoice.paid invoice.payment_failed
                      customer.subscription.updated customer.subscription.deleted].freeze

  def process_payload
    stripe_event = verified_event or return
    return head :ok unless HANDLED_EVENTS.include?(stripe_event.type)

    event = find_or_create_event(stripe_event)
    event.with_lock do
      return head :ok if event.processed? || event.ignored?
      reason = StripeBilling::EventHandler.new(event).call
      reason ? event.mark_ignored!(reason) : event.mark_processed!
    end
    head :ok
  end
  # verified_event: 401 sem segredo/assinatura inválida; 400 JSON quebrado.
  # find_or_create_event: find_or_create_by! + rescue RecordNotUnique → find_by!.
end
```

- Falha inesperada do handler (ex. `RecordInvalid`): deixar estourar → rollback (linha volta a pending) → 500 → retry do Stripe. NÃO capturar como `failed` (engoliria o retry).
- [ ] Spec com assinatura REAL (conferir a API exata de `Stripe::Webhook::Signature.compute_signature` no source da gem v18 antes de escrever; header `t=<ts>,v1=<sig>`): 401 sem segredo; 401 assinatura errada; 400 JSON quebrado; 200 + zero linha pra tipo não tratado; despacho dos 5 tipos com payload fixo mínimo; **idempotência**: mesmo event_id 2x → uma mutação (updated_at congelado + count 1); órfão → 200 + `ignored`.
- [ ] Commit.
